### New to GitHub?

GitHub isn't only a developer tool.
It's where versioned documents live and change in the open: code, standards, and even law (the [DC Code is published on GitHub](https://github.com/DCCouncil/law-html)).
If you work with policy, legislation, or anything that gets revised, it's worth knowing the basics.
You only need four ideas, and none of them require writing code:

* **Issue**: a conversation thread. Use one to ask a question, suggest a topic, or share a link.
* **Comment**: reply on an issue, just like a discussion forum.
* **Edit**: click the pencil icon on any file to propose a change. GitHub turns it into a *pull request* for review.
* **History**: every change is recorded with who made it, when, and why, so nothing is lost.

Start with [CONTRIBUTING.md](CONTRIBUTING.md) for step-by-step instructions, or try GitHub's 10-minute [Hello World](https://docs.github.com/en/get-started/start-your-journey/hello-world) tutorial.
Still stuck? Contact Fred via email or ask on the Friday call, and a group member can walk you through it.
See [Working in the Open](https://blockchain-working-group.github.io/agendas/resources/) on the Resources page for how federal agencies (GSA, Commerce, DoD) approach open collaboration.
