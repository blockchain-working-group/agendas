# Resources

The curated resource list now lives in one place: **[docs/_data/resources.json](docs/_data/resources.json)**, which renders as the [Resources page](https://blockchain-working-group.github.io/agendas/resources/) on the working group site.

Keeping a single source of truth avoids two lists drifting apart.

## To add a resource

- Edit [`docs/_data/resources.json`](docs/_data/resources.json) directly (add an item under the appropriate `section`), or
- Open a [New Issue](https://github.com/blockchain-working-group/agendas/issues/new) or submit a Pull Request, and a group member can add it.

Each entry supports a `title`, an optional `meta` (source and date), an optional `summary`, and a `url`.

## Links from closed issues

Links shared in GitHub issues, organized by issue, are archived in [ISSUE_REFERENCES.md](ISSUE_REFERENCES.md).
Promote any that belong on the Resources page into `resources.json`.
