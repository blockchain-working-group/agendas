# Efforts

Small working group projects, each aimed at publishing a document.
Each file is the working copy of one effort, and the published document is its product.

Nothing here is an official ACT-IAC or working group position until it is published.
Contributions are welcome: click the pencil icon on any file to propose an edit, or [open an issue](https://github.com/blockchain-working-group/agendas/issues/new).
New to GitHub? See the [README](../README.md#new-to-github).

## Front matter

Each effort starts with:

```yaml
---
status: exploring
product: What this effort will publish
started_at: 2024-09-22
ended_at:
issue: https://github.com/blockchain-working-group/agendas/issues/31
---
```

- `status` is where the effort stands, from the list below.
- `product` names the document the effort intends to publish.
  It can say "To be decided" while the effort is exploring.
- `started_at` is when the effort began, usually the date of the issue that started it.
- `ended_at` stays empty until the effort is published or archived.
- `issue` links the GitHub issue where it started.

## Status

1. `exploring`: gathering ideas and questions; the product isn't decided yet.
2. `drafting`: the product is decided and a draft is being written.
3. `review`: the draft is ready for the group to read and comment on.
4. `published`: the product is out; set `ended_at` and link the published document.
5. `paused` or `archived`: no one is working on it now; set `ended_at` if archived.
